# AI BOOTH ANALYTICS

Stack-chan（M5Stack CoreS3）の内蔵カメラを使い、イベントブースの行動を匿名集計するPoCです。

現在は通過・立ち止まり・ブース来訪・滞在時間の実機PoCまで検証済みです。

> [!IMPORTANT]
> これは商用品質の監視システムではなく、1台・1環境で段階的に検証したPoCです。混雑、遮蔽、逆光、Wi-Fi品質によって精度は変わります。現在の通過数はユニーク人数ではなく延べ通過回数です。

- STEP 1: CoreS3のカメラ映像をWi-Fiで配信する（実機確認済み）
- STEP 2: PCブラウザに映像を表示する（実機確認済み）
- STEP 3: 人物検出と匿名追跡（実機確認済み）
- STEP 4: ライン通過カウント（実測10回・AI 10回を確認済み）
- STEP 5: 2秒立ち止まり判定（実機表示確認済み）
- STEP 6: ブース来訪・滞在時間（来訪1人・平均17.6秒を実機確認済み）

## 今回できたもの

- `firmware/cores3-camera-stream`: CoreS3用MJPEG配信ファームウェア
- `pc-viewer`: PCブラウザ用の映像確認画面
- `pc-analyzer`: 人物検出・ByteTrack匿名追跡・通過・立ち止まり・来訪・滞在時間のローカルWebアプリ
- `docs/architecture.md`: 採用技術と全体設計
- `docs/setup-step1.md`: バックアップから実機確認までの手順

ファームウェアは顔認識・顔検出を行いません。映像の保存機能もありません。

## 白猫Stack-chanとの関係

現在の白猫相棒AIとカメラ配信は別ファームウェアです。同時には起動しません。

実機検証では、元の16MBフラッシュ全体をバックアップして照合した後にカメラ用ファームウェアを一時的に書き込み、検証終了後に完全バックアップから白猫モードへ復元しました。元の白猫プロジェクトのソースは変更していません。

## 最短の確認手順

実機へ書き込む前に、必ず [STEP 1実機手順](docs/setup-step1.md) のバックアップ作業から進めてください。

CoreS3への書き込み後、CoreS3の画面に表示されたIPアドレスをMacのブラウザへ入力します。

```text
http://192.168.x.x/
```

このURLだけでも映像を確認できます。PC確認画面を使う場合は別のターミナルで次を実行します。

```bash
cd pc-viewer
python3 -m http.server 8080
```

その後、ブラウザで `http://localhost:8080` を開きます。

## STEP 1・2の成功条件（達成済み）

- CoreS3とMacが同じ2.4GHz Wi-Fiに接続できる
- `http://<CoreS3のIP>/health` に `ok` と表示される
- `http://<CoreS3のIP>/stream` で映像が連続表示される
- PC確認画面で30分以上、映像停止やCoreS3再起動が起きない

## PC解析アプリ

解析はMac内だけで行い、生映像は保存しません。初回だけ人物検出モデルをダウンロードします。

```bash
python3 -m venv .venv-ai
.venv-ai/bin/python -m pip install -r requirements-ai.txt
.venv-ai/bin/python pc-analyzer/app.py \
  --stream-url http://<CoreS3のIP>/stream
```

起動後、ブラウザで `http://127.0.0.1:8765` を開きます。人物を検出すると、起動中だけ有効な `person_001` 形式のIDを表示します。

- 黄色線: ライン通過
- 青枠: 2秒以上の立ち止まり
- 紫枠: 通路側から入ったブース来訪と、退出までの滞在時間

紫枠内で初めて検出された人は来訪にしません。いったん紫枠の外で検出された匿名IDが中へ入った場合だけ、1人として数えます。

## プライバシー

- 顔認識、顔照合、属性推定を行いません
- 動画・静止画を保存しません
- 匿名IDは解析サーバーの起動セッション内だけで使います
- 現在はイベントデータも永続保存しません
- 今後SQLiteへ保存する場合も、日時・通過・立ち止まり・来訪・滞在時間などの匿名イベントだけを対象にします
