# 🐾 Stack-chan AI Booth Analytics

> 手持ちの **Stack-chan + Mac + Wi-Fi** だけで、イベントブースの効果をどこまで見える化できる？

Stack-chan（M5Stack CoreS3）の内蔵カメラ映像をMacへ送り、AIで人の動きを**匿名で集計するPoC（試作品）**です。

顔認識は行わず、映像も保存しません。現在は、通過・立ち止まり・ブース来訪・滞在時間まで実機で動作を確認できています 🎉

## ✨ 何ができるの？

| 機能 | 仕組み | 実機検証 |
| --- | --- | --- |
| 🚶 通過カウント | 人が仮想ラインを横切るたびに加算 | 実測10回 → AI 10回 |
| 👀 立ち止まり判定 | 注目ゾーンに2秒以上いる人を判定 | 表示・集計を確認 |
| 🏠 ブース来訪判定 | 通路側からブースゾーンへ入った人を加算 | 来訪1人を確認 |
| ⏱️ 滞在時間 | ブースへ入ってから出るまでを計測 | 平均17.6秒を確認 |
| 🆔 匿名トラッキング | `person_001` のような一時IDで追跡 | YOLO11n + ByteTrack |

> [!IMPORTANT]
> これは商用品質の監視システムではなく、1台・1環境で段階的に検証したPoCです。混雑、遮蔽、逆光、Wi-Fi品質によって精度は変わります。現在の「通過数」はユニーク人数ではなく、ラインを横切った**延べ通過回数**です。

## 🚀 動かし方

### 1. まずStack-chanをバックアップする

既存の白猫Stack-chanを元に戻せるように、**書き込み前に16MBフラッシュ全体をバックアップ**してください。

詳しい手順は [📘 STEP 1 実機セットアップガイド](docs/setup-step1.md) にあります。バックアップ成功を確認する前に、カメラ用ファームウェアを書き込まないでください。

### 2. カメラ映像を確認する

CoreS3へカメラ用ファームウェアを書き込み、画面に表示されたIPアドレスをブラウザへ入力します。

```text
http://192.168.x.x/
```

次のURLで状態と映像を個別に確認できます。

```text
http://<CoreS3のIP>/health
http://<CoreS3のIP>/stream
```

映像だけをPC用画面で見る場合：

```bash
cd pc-viewer
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます。

### 3. AI解析アプリを起動する

解析はMac内だけで行います。初回起動時のみ人物検出モデルをダウンロードします。

```bash
python3 -m venv .venv-ai
.venv-ai/bin/python -m pip install -r requirements-ai.txt
.venv-ai/bin/python pc-analyzer/app.py \
  --stream-url http://<CoreS3のIP>/stream
```

ブラウザで `http://127.0.0.1:8765` を開いてください。

### 4. 画面の見方

- 🟡 **黄色線**：横切るたびに延べ通過回数を `+1`
- 🔵 **青い注目ゾーン**：2秒以上いると「立ち止まり」
- 🟣 **紫のブースゾーン**：通路側から入ると「来訪」、出るまでを滞在時間として計測
- 🟢 **緑の人物枠**：人物を検出し、一時的な匿名IDで追跡

紫枠の中で初めて検出された人は来訪にしません。いったん枠外で検出された匿名IDが中へ入った場合だけ、来訪として数えます。

## 🔒 プライバシーを最優先

このPoCは、個人を特定するためのシステムではありません。

- ❌ 顔認識・顔照合をしません
- ❌ 性別・年齢・人種・民族・感情を推定しません
- ❌ 動画・静止画を保存しません
- ✅ 匿名IDはアプリ起動中だけ有効です
- ✅ 将来保存する場合も、日時・通過・立ち止まり・来訪・滞在時間などの匿名イベントだけを対象にします

## 🐱 白猫Stack-chanとの切り替え

白猫相棒AIとカメラ配信は**別ファームウェア**のため、同時には起動しません。

実機検証では、元の16MBフラッシュ全体をバックアップして照合した後にカメラ用ファームウェアを一時的に書き込み、検証終了後に完全バックアップから白猫モードへ復元しました。元の白猫プロジェクトのソースは変更していません。

```text
🐱 白猫モード ── バックアップ ──▶ 📷 カメラモード
🐱 白猫モード ◀── 完全復元 ───── 📷 カメラモード
```
